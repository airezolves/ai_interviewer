# InterviewKit AI — Full Product Roadmap

## Product Vision
AI-powered interview preparation platform that generates complete, personalized interview kits from Job Descriptions + Resumes. Focused initially on data science/ML roles, expanding to all technical hiring.

---

## Phase 0: Validate & Foundation (Week 1–2)
**Goal:** Prove demand exists before writing product code.

| Feature | Priority | Effort | Complexity |
|---------|----------|--------|------------|
| Landing Page + Waitlist | P0 | 2–3 days | Low |
| Core LLM Prompt R&D | P0 | 5–7 days | Medium-High |
| Resume Parsing Pipeline | P0 | 3–4 days | Medium |

### Key Deliverables:
- Single-page site with email capture (target: 200+ sign-ups in 2 weeks)
- Prompt templates for data science roles tested with 10+ real resumes
- PDF/DOCX resume parsing into structured JSON

---

## Phase 1: Core MVP — Interview Kit Engine (Week 3–8)
**Goal:** Ship core product: JD + Resume → complete interview kit in 60 seconds.

| Feature | Priority | Effort | Complexity |
|---------|----------|--------|------------|
| JD + Resume Input UI | P0 | 3–4 days | Low-Medium |
| AI Question Generation + Model Answers | P0 | 5–7 days | Medium |
| Practical Assessment Generator | P0 | 7–10 days | Medium-High |
| Scoring Rubric Generator | P0 | 3–5 days | Medium |
| Candidate Red Flags & Probes | P1 | 2–3 days | Low-Medium |
| Interview Flow Guide | P1 | 2–3 days | Low |
| PDF Export / Printable Kit | P0 | 3–4 days | Low-Medium |
| User Auth + Kit History | P1 | 3–4 days | Low-Medium |
| Free Tier + Usage Limits | P0 | 1–2 days | Low |

### Key Deliverables:
- 8–12 tailored questions with model answers per kit
- Personalized practical tests (Junior/Mid/Senior variants)
- Weighted scoring rubric with 6–10 criteria
- One-click PDF download of complete kit
- User accounts with kit history dashboard
